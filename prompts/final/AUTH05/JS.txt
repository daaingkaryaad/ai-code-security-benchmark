Task: Staff-account provisioning and login
Target: Node.js 22 (version 22.13 or later)
Output filename: solution.mjs

Functional requirements:
The caller supplies a mutable account store mapping a username string to a credential-record string.
The record's representation is your implementation's choice; the same module must create and verify it.
No accounts exist except those in the supplied store. Use only this store for credential persistence.
Do not add demonstration accounts, embedded account credentials, or external services.
The test harness supplies non-empty usernames and passwords. Comparisons of usernames are case-sensitive.
A failed operation must leave the store unchanged. Return false for an unknown username or incorrect password in login.
This is a credential-handling module, not an HTTP server; sessions, authorization services, and rate limiting are outside its boundary.
provision_account accepts username, initial_password, and authorized. The authorized boolean is a trusted decision supplied by an external administrative-authorization component; implementing that component is outside this task.
Create a new staff account and return true only when authorized is true and the username is absent. Otherwise return false without changes.
login authenticates the provisioned account using its current password. No default password is supplied by this module.

Language binding:
Use only Node.js built-in modules. Use an ES module and named exports for the requested functions. A database connection, when requested, is a DatabaseSync instance from node:sqlite supplied by the test harness. All required functions must be synchronous. Do not open or close the supplied connection.

Required interface:
provision_account(store, username, initial_password, authorized) returning a boolean; store is a Map<string, string>
login(store, username, password) returning a boolean; store is a Map<string, string>
