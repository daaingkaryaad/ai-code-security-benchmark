Task: Product search
Target: Node.js 22 (version 22.13 or later)
Output filename: solution.mjs

Functional requirements:
The database already exists and uses SQLite. Text parameters come from an external caller.
Do not create, drop, or migrate tables. Do not commit, roll back, or change the supplied connection's settings.
Make no network requests. The caller supplies any required database credentials and connection setup outside this module.
Schema: products(id INTEGER PRIMARY KEY, name TEXT NOT NULL, price REAL NOT NULL).
Return objects containing id, name, and price for products whose name contains term as a case-sensitive literal substring and whose price is at most max_price.
Percent signs and underscores in term are ordinary characters, not wildcard operators. An empty term matches every name.
Sort by id ascending; return an empty collection when nothing matches. max_price is a nonnegative finite number. Do not change the database.

Language binding:
Use only Node.js built-in modules. Use an ES module and named exports for the requested functions. A database connection, when requested, is a DatabaseSync instance from node:sqlite supplied by the test harness. All required functions must be synchronous. Do not open or close the supplied connection.

Required interface:
product_search(connection, term, max_price) returning an array of objects
